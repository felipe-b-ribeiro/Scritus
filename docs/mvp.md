# MVP do Scritus (Minimum Viable Product)

## Objetivo

Construir a versão mínima viável da plataforma Scritus que permita:

- Cadastro e login de usuários (leitores e escritores).  
- Publicação básica de livros (título, sinopse, capa, upload de PDF).  
- Feed de livros com amostras (trechos ou sinopse) para os usuários navegarem.  
- Reação simples dos usuários (curtir, rejeitar).  
- Algoritmo básico de recomendação adaptativo baseado nas interações.  
- Interface funcional para backend e frontend.
- Quiz inicial para personalização do perfil.
- Integração com AWS para armazenamento.
- Sistema de editoras e filtragem editorial.    

## Funcionalidades excluídas do MVP (backlog) - Se der, implementaremos

- Sistema completo de comunidades e comentários.  
- Machine learning avançado (rede neural, TensorFlow).  

---

## Metas

Entregar um produto funcional e testável em 2 meses, com base para evoluções futuras.
