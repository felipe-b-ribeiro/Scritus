# Documentação do Scritus

Esta pasta guarda todos os documentos que explicam o projeto, suas decisões e processos.

Arquivos importantes:

- `mvp.md` — Define o escopo mínimo viável do projeto.  
- `arquitetura.md` — Descreve a organização e fluxo do sistema.  
- `deploy.md` — Guia para rodar o projeto localmente e planos para produção.

Mantenha os documentos atualizados para evitar dúvidas e garantir alinhamento.
