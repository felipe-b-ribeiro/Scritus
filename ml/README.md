# Machine Learning — O sommelier do restaurante

Aqui é onde o Scritus aprende seus gostos e escolhe os melhores “vinhos” (livros) para você.

## O que tem aqui?

- `data/` — O estoque com informações usadas para treinar o sommelier.  
- `notebooks/` — Cadernos de anotações e experimentos para aprender o que funciona.  
- `models/` — O sommelier pronto, com toda a expertise guardada.  
- `src/` — O código que faz o sommelier trabalhar junto com o backend.

## Como usar?

- Precisa do Python e algumas “ferramentas de cozinha” (bibliotecas).  
- Use os cadernos para testar ideias.  
- Use os scripts para integrar tudo na aplicação.
